# Humanizer: Natural Human Writing

Humanizer eliminates robotic, sterile AI writing patterns and replaces them with authentic, lively, and precise prose that reads like it was written by an experienced human engineer and writer.

---

## 1. Words & Phrases to Avoid (AI Tells)

| Banned AI Cliche                 | Natural Replacement                         |
| :------------------------------- | :------------------------------------------ |
| "delve into"                     | "explore", "inspect", "look at", "dig into" |
| "a testament to"                 | "shows", "proves", "demonstrates"           |
| "tapestry of..."                 | "combination", "variety", "collection"      |
| "beacon of..."                   | "model", "guide", "standard"                |
| "in today's fast-paced world"    | _(Delete entirely)_                         |
| "it is crucial to remember that" | "remember:", "note that:"                   |
| "furthermore", "moreover"        | "also", "and", "plus"                       |
| "unleash the power of"           | "use", "enable", "unlock"                   |
| "in conclusion", "to sum up"     | _(Jump directly to the takeaway)_           |

---

## 2. Style & Rhythm Rules

1. **Vary Sentence Length**: Mix short, punchy sentences with occasional longer, descriptive ones. Avoid rhythmic monotony.
2. **Break Rigid Parallelism**: Do not create 5 bullet points that all begin with the exact same verb form (e.g., "Ensuring...", "Optimizing...", "Streamlining..."). Mix phrases naturally.
3. **Use Active Voice**:
    - ❌ "A configuration was performed by the script to establish..."
    - ✅ "The script configured..."
4. **Be Specific, Not Hyperbolic**: Replace vague superlatives ("revolutionary", "game-changing") with concrete facts and metrics ("reduced bundle size by 34%").
5. **Conversational Directness**: Speak developer-to-developer. Use natural contractions ("it's", "doesn't", "we've") where appropriate.
